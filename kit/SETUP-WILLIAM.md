# William quick-start

For the meeting you need nothing installed — the sites are live links and the docs render right on GitHub.

To RUN the tools later: Python 3.11+, `yt-dlp` and `ffmpeg` on PATH, and a Gemini API key in an env var (text Grady for it — never put keys in this repo or any repo). The mailer needs a Gmail app password via env var too; steps are in `tools/mailer/ARM-IT.md`.
